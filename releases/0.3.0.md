# 0.3.0

A command line that does what the window does, four new ways to read the same
documents, notes and a repository doctor built in, and undo for the whole
repository.

- miaz is a real command line: add, delete, rename, search, read notes and run OCR, on a machine with no desktop toolkit installed; a plugin can add commands of its own
- Four new ways to look at the same documents: a Grid of pages, a Timeline, Conversations between the two parties of a document, and the Filenames as they are on disk
- The first page of the selected document, in the workspace and in the rename dialog, so a filename that says nothing can be settled without opening the file
- Notes are part of MiAZ rather than a plugin. They moved into the repository's own .conf/notes folder, and a repository written by an older MiAZ moves them itself when it opens
- MiAZDoctor checks a repository in one pass: names that break the convention, values nobody uses, documents with the same content, files that went missing. It can run when the repository opens, and every finding puts the documents it names on screen
- MiAZContacts reads the senders and recipients as contacts, each with an address, a phone number and an IBAN. The contact manager imports and exports them as vCard files, so they can leave as easily as they arrived
- MiAZHistory: undo and redo for the whole repository, with a history of what changed
- MiAZRelated: the documents around the one you are reading
- Documents can be dragged out of MiAZ into another application
- The window fits a phone
- Repository Settings is three tabs instead of six, and a plugin is configured in it rather than in a dialog of its own
- What acts on the documents is on a toolbar above them, along with the views, Review and a menu to choose the columns
- An empty repository can be filled again: the empty page has its own Add button, with an entry per enabled import plugin
- miaz search --from and --to work at last, and a repository written by a newer MiAZ is refused instead of opened
