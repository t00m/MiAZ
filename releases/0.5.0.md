# 0.5.0

Help built into the application, and a new plugin that records what each
document is worth.

- F1 opens the help in a window of its own, with a page for every feature and every bundled plugin. It works offline, follows the light or dark style, and is also in the Browser tab and at t00m.github.io/MiAZ
- The keyboard shortcuts list moved from F1 to Ctrl+?
- New MiAZOikos plugin: record a document as an income or an expense, with its amount and currency, for one document or many at once
- MiAZOikos adds up the selected documents, or every document on screen when none is selected, per currency, as cards and a chart grouped by year, month, group, sender or purpose
- MiAZOikos adds an Amount column to the Details table, expenses negative in red and incomes in green, and a sidebar filter for incomes, expenses and documents still to record
- Plugins can now add a column to the Details table and a filter to the sidebar
