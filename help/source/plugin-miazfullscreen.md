# Use fullscreen

1. Enable the plugin in **Repository settings > Plugins**.
2. Press the fullscreen button in the header bar, or <kbd>F11</kbd>. Press it
   again to leave fullscreen.

To hide the button and keep only the key, turn off **Display fullscreen toggle
button** in **Repository settings > Settings**.
