# Export to a folder

1. Select the documents.
2. Right-click and open **Documents > Export > Export to directory**.
3. **Select folder** for the copies.
4. Optionally:
   - **Folders by date**: one folder per **Year**, and inside it per **Month**.
   - **Folders by field**: one folder per value of the fields you tick.
   - **Use readable names**: rename the copies with descriptions instead of
     codes, for someone who does not know MiAZ names.

   **Example** shows where one document would land.
5. Confirm.

Only the copies change. The documents in the repository keep their names.
