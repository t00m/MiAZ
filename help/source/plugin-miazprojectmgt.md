# Group documents into projects

A project gathers documents from any sender, date or group: everything about
buying a house, a trip, a legal case. This plugin is enabled in every new
repository.

## Create projects {#create}

Right-click and open **Documents > Projects > Manage projects**
(<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>), or use **Repository settings >
Metadata**, to create, rename or delete projects.

## Assign documents {#assign}

- For many: select them and choose **Assign document(s) to projects**
  (<kbd>Ctrl</kbd>+<kbd>P</kbd>). A document can belong to several projects.
- For one: press <kbd>F2</kbd> and use the **Projects** tab.

**Unassign document(s) from any projects**
(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) takes them out of every
project.

## Show a project {#show}

Pick the project in the project filter of the sidebar. Its documents are
shown whatever their date, and whether or not their names are complete, so
nothing in the project is hidden by the other checks.

A project still used by documents cannot be disabled.
