# Import documents from a ZIP file

1. Enable the plugin in **Repository settings > Plugins**.
2. Choose **Import documents from ZIP** from the **Add** menu or the
   right-click menu.
3. Select the ZIP file.

Every file inside is added and named the way [Add
documents](howto-add-documents.md) names a new file. Those that do not yet
have a complete name wait in Review.
