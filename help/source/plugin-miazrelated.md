# Find the documents of the same case

Documents with the same Concept belong to the same case. MiAZRelated finds
them from any one of them.

1. Select one document.
2. Right-click and open **Documents > Search > Show the documents belonging to
   the same case**.

The documents are shown in two groups:

- **The same parties**: same Concept, between the same sender and recipient,
  the case as one side kept it.
- **Somebody else**: same Concept with another party, which is how a request
  and its answer find each other.

Press **Open** on any of them to open it.

This depends on reusing the Concept, see [The Concept links
documents](explanation-filename-convention.md#concept).
