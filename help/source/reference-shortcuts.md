# Keyboard shortcuts

Press <kbd>Ctrl</kbd>+<kbd>?</kbd> in MiAZ to see this list in the
application. Shortcuts marked *list* work only while the document list has
focus, so they never fire while you type in a search box.

## Application {#application}

| Action | Shortcut |
|---|---|
| Settings | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| Repository management | <kbd>Ctrl</kbd>+<kbd>R</kbd> |
| Repository settings | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> |
| Keyboard shortcuts | <kbd>Ctrl</kbd>+<kbd>?</kbd> |
| Help | <kbd>F1</kbd> |
| Main menu | <kbd>F10</kbd> |
| Quit | <kbd>Ctrl</kbd>+<kbd>Q</kbd> |

## Documents {#documents}

| Action | Shortcut |
|---|---|
| Add new document(s) | <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| Add documents from a directory | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> |
| Open document (list) | <kbd>Enter</kbd> |
| Rename document (list) | <kbd>F2</kbd> |
| Delete documents (list) | <kbd>Delete</kbd> |
| Select all documents (list) | <kbd>Ctrl</kbd>+<kbd>A</kbd> |
| Copy document names | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> |
| Mass renaming | <kbd>Ctrl</kbd>+<kbd>M</kbd> |
| Create a new note | <kbd>Ctrl</kbd>+<kbd>N</kbd> |
| See all notes | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> |

## Views {#views}

| Action | Shortcut |
|---|---|
| Details | <kbd>Ctrl</kbd>+<kbd>1</kbd> |
| Grid | <kbd>Ctrl</kbd>+<kbd>2</kbd> |
| Timeline | <kbd>Ctrl</kbd>+<kbd>3</kbd> |
| Conversations | <kbd>Ctrl</kbd>+<kbd>4</kbd> |
| Filenames | <kbd>Ctrl</kbd>+<kbd>5</kbd> |

## Workspace {#workspace}

| Action | Shortcut |
|---|---|
| Search in all fields | <kbd>Ctrl</kbd>+<kbd>F</kbd> |
| Search in Concept field | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| Clear all filters (list) | <kbd>Esc</kbd> |
| Toggle sidebar | <kbd>F9</kbd> |
| Toggle document preview | <kbd>F8</kbd> |
| Choose the columns to show | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> |

Plugins can add their own shortcuts. They appear in the in-app list under
**Plugins**.
