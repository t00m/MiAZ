# Add documents

MiAZ always copies a document into the repository. The original file is not
moved or changed.

## Add one or more files {#files}

1. Press **Add** in the header bar and choose **Add new document(s)**, or press
   <kbd>Ctrl</kbd>+<kbd>I</kbd>.
2. Select the files and confirm.

## Add a folder {#folder}

1. Press **Add** and choose **Add documents from a directory**, or press
   <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd>.
2. Pick the folder.
3. MiAZ asks whether to **Include subfolders** and shows how many files each
   choice would add. Choose and confirm.

## Drag and drop {#drop}

Drag files or folders from your file manager onto the document list. Dropping a
folder asks the same question about subfolders.

!!! note
    Adding many documents at once runs in the background. The list refreshes
    once at the end instead of after every file.
