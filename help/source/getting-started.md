# Get started with MiAZ

This tutorial takes you from an empty MiAZ to a first document filed under a
proper name. It takes about ten minutes.

## Create a repository {#create-repository}

A repository is the folder where MiAZ keeps your documents. The first time you
start MiAZ, an assistant helps you create one.

1. On **Welcome**, read how documents are named and press **Next**.
2. On **Create a repository**, type a **Repository name** and choose a
   **Location**. MiAZ derives a short key from the name.
3. On **Countries**, enable the countries you exchange documents with. You can
   change this list later.
4. On **Summary**, check what was set up and press **Finish**.

Groups, purposes, senders and recipients already have a starting list, so you
can file a document straight away.

## Add a document {#add-document}

Press **Add** in the header bar, or <kbd>Ctrl</kbd>+<kbd>I</kbd>, and pick a
file. You can also drag files from your file manager onto the document list.

MiAZ copies the file into the repository. Your original stays where it was.

## Give it a proper name {#rename}

A new document usually needs a better name. Select it and press
<kbd>F2</kbd> to open the rename dialog.

Fill in the seven fields, or use **Detect** to let MiAZ read the date, country,
sender and recipient from the document itself. Press **Preview** to check the
new name, then **Rename**.

!!! tip
    Reuse the same Concept for documents that belong together, such as every
    payment of the same loan. MiAZ can then show them as one conversation.
