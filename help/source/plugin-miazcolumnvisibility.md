# Choose and keep the visible columns

**Choose the columns to show** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>)
works without any plugin, but forgets the choice when MiAZ closes.
MiAZColumnVisibility remembers it for each repository.

1. Enable the plugin in **Repository settings > Plugins**.
2. Right-click a column header in **Details** and tick the columns to show.

The same choices are in **Repository settings > Settings**, under **Workspace
columns**.
