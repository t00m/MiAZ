# Set how often a document comes

A payslip comes monthly, a tax return yearly, a receipt once. MiAZPeriodicity
records that, so you can list what should arrive every month.

## Set it {#set}

- For one document: press <kbd>F2</kbd> and open the **Periodicity** tab.
- For many: select them, right-click and open **Documents > Periodicity > Set
  periodicity**.

Values include Daily, Weekly, Bi-Weekly, Monthly, Bi-Monthly, Quarterly,
Semi-Annual, Yearly and On demand. Every document starts as **On demand**.

**Unset periodicity** puts the selected documents back to the default.

## Filter by it {#filter}

The plugin adds a periodicity filter to the sidebar, below the separator.

## Change the list {#manage}

**Manage periodicity**, or **Repository settings > Metadata**, lets you enable
or disable values.
