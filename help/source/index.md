# MiAZ Help

MiAZ keeps your personal documents in order by giving each one a name that
says what it is: when it is from, who sent it, who received it and what it is
about. The folder is the whole database, so your documents stay ordinary files
you can open, copy and back up with any other tool.

New here? Start with [Get started with MiAZ](getting-started.md).
