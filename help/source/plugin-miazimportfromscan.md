# Scan with your scanning application

MiAZImportFromScan starts the scanning program you already use, such as GNOME
Document Scanner, so scanning is one click away from MiAZ.

1. Enable the plugin in **Repository settings > Plugins**.
2. In **Repository settings > Settings**, pick the **Scanner application**.
   MiAZ lists the ones it finds; you can also type the **Scanner command**.
3. Choose **Scan a document** from the **Add** menu or the right-click menu.

Save the scan from that program, then add it to MiAZ as any other file, see
[Add documents](howto-add-documents.md). To scan straight into the repository
instead, use [MiAZAutoScan](plugin-miazautoscan.md).
