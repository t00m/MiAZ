# Search and filter documents

The sidebar on the left holds every filter. If it is hidden, press
<kbd>F9</kbd>. All filters combine: a document is shown only when it passes
every one.

## Search {#search}

- **Search in all fields** (<kbd>Ctrl</kbd>+<kbd>F</kbd>): any part of any
  field or its description, for example a sender's name.
- **Search in Concept field** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>):
  only the Concept.

## Filter by date {#date}

The date filter shows recent periods first: **This month**, **Since past
month**, **Since last 3 months** and so on up to **Since ten years ago**, then
**Future** and **All documents**. Pick **All documents** to see everything.

## Filter by field {#fields}

Pick a value in the Country, Group, Sent by, Purpose or Sent to filter. Each
one lists only the values the documents on screen use, so the lists shrink as
you narrow.

Below them, **Only with notes** keeps the documents that have notes. Enabled
plugins add their own filters after a separator, for example
[income or expense](plugin-miazoikos.md#missing) or periodicity.

## See and remove active filters {#tags}

Each active filter shows as a tag above the documents. Click a tag to remove
that filter. To remove them all, press **Clear all filters** in the header bar,
or <kbd>Esc</kbd> while the document list has focus.

The number under the sidebar is how many documents are shown.
