# Export to a text editor

1. Select the documents.
2. Right-click and open **Documents > Export > Export to text editor**.

The names, one per line, open in your default text editor. To put them on the
clipboard instead, use **Copy document names**
(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>).
