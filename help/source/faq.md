# Frequently asked questions

## Where are my documents stored? {#storage}

In the repository folder you chose. They are plain files with descriptive
names. MiAZ keeps its settings for that repository in a `.conf` folder inside it.

## Is my original file changed when I add it? {#original}

No. MiAZ copies it into the repository and leaves the original alone.

## Can I have more than one repository? {#repositories}

Yes. Open **Repository management** (<kbd>Ctrl</kbd>+<kbd>R</kbd>) to add one
or switch between them.

## Why is a document in the Review list? {#why-review}

Its name does not have seven fields, or one of its values is not enabled in the
repository. See [Documents waiting for review](explanation-filename-convention.md#review).

## Why does a document have the date 99991231? {#unknown-date}

MiAZ could not read a date from it and did not guess. Rename it and set the
right date. See [Unknown dates](explanation-filename-convention.md#unknown-date).
